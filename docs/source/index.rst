DESE documentation
==================

DESE (Discrete Event Simulation Engine) is a schema-driven discrete-event
simulation tool with a Tkinter GUI: build a process model (entities,
relationships, routing rules), run a simulation against it, and export the
resulting event log as CSV.

This site is generated from the docstrings in ``src/dese`` -- every module,
class and function listed under *API Reference* links back to its own page.
